## 这是什么

EmotionAI Pro 是一个给 AstrBot 使用的「情感与关系」插件。它不改变 bot 的人设，而是在对话前后维护一套会变化的好感度、亲密度、情绪与关系阶段，再把这些状态作为参考注入回复，让角色对同一个人的态度能随着相处逐渐变化。

它适合群聊互动、私聊陪伴、角色扮演和剧情养成：高好感时更愿意记住细节、主动关心；好感降低时会更冷淡、更有边界感。插件不替代 AstrBot 的会话历史，也不会改写框架的数据库——长期记忆、用户状态和心情都保存在插件自己的数据目录中。

### 项目背景

本项目基于原作者 **asakiyoshi** 的 EmotionAI Pro 修复维护，并融合 [EmotionAI](https://github.com/tengtian3/astrbot-plugin-emotionai) 与 [FavourPro](https://github.com/Catfish872/astrbot_plugin_favourpro) 的思路。当前由 **foorgange** 持续维护，重点放在：好感度真正参与记忆与态度、心情对回复的自然影响、长期运行的稳定性，以及升级时不破坏已有数据。

### 设计边界

- 情感状态是「数值 + 提示词」的模拟，不是真实意识；它的价值是让角色表现更连贯，而不是宣称 bot 真的有感情。
- 情感分析会调用 LLM；辅助模型不可用时会走本地兜底，不阻塞主回复。
- 不修改 AstrBot 核心，不接管 `system_prompt`；动态内容只追加在请求尾部，避免破坏前缀缓存。

## 安装与部署

### 环境要求

| 项目 | 要求 |
|---|---|
| AstrBot | 4.x（开发验证：4.26.8 / 4.28.0） |
| Python | 3.8 及以上 |
| 必需依赖 | `pydantic>=2.0.0`、`aiofiles>=23.0.0` |
| 可选依赖 | `psutil`、`watchfiles`、`xxhash`（缺失时自动降级，不影响启动） |
| 模型 | 一个主对话模型；辅助情感分析模型可选 |
| 数据库 | 不需要额外数据库，使用本地 JSON |

### 方式一：AstrBot 官方插件市场安装（推荐）

1. 启动 AstrBot，打开 WebUI（默认 `http://127.0.0.1:6185`）。
2. 进入「插件市场 / 插件商店」，搜索 **EmotionAI Pro**，或搜索包名 **`astrbot_plugin_emotionai_pro`**。
3. 点击安装，等待插件文件和依赖下载完成。
4. 在插件配置中至少设置 `bot_name`（你的角色名）；需要更强的情感分析时可再指定辅助 LLM。
5. 保存配置，重启 AstrBot 或在 WebUI 中重载插件。
6. 在聊天中发送 `/好感度` 或 `/心情`，确认插件已加载。

> 如果插件市场暂时搜不到，或依赖没有自动装好，可以用下面的手动方式；插件本身不依赖任何私有服务。

### 方式二：手动安装

```bash
# 进入 AstrBot 的插件目录（按你的实际安装路径调整）
cd AstrBot/data/plugins

git clone https://github.com/foorgange/astrbot-plugin-emotionai_pro.git

# 安装依赖（使用 AstrBot 所在 Python 环境）
python -m pip install -r astrbot-plugin-emotionai_pro/requirements.txt
```

安装后重启 AstrBot。若使用 Docker，在容器内执行：

```bash
docker exec -it astrbot bash
cd /AstrBot/data/plugins
git clone https://github.com/foorgange/astrbot-plugin-emotionai_pro.git
python3 -m pip install -r astrbot-plugin-emotionai_pro/requirements.txt
exit

# 回到宿主机重启
docker restart astrbot
```

### 首次配置建议

| 配置项 | 建议 |
|---|---|
| `bot_name` | 必填，写你的角色名；留空会尝试从 AstrBot persona 自动提取 |
| `enable_secondary_llm` | 建议开启；没有辅助模型时可用主模型兜底 |
| `secondary_llm_provider` / `secondary_llm_model` | 可选；指定一个稳定、便宜、响应快的模型 |
| `session_based` | 想让每个群聊/私聊独立计算情感时开启 |
| `mood_influence_strength` | 心情影响强度，默认 `0.7`；想更明显可调到 `0.85~1.0` |
| `enable_memory_recall` | 是否注入具体记忆片段；关闭后只注入关系统计 |

### 升级、备份与卸载

- **升级**：优先用插件市场更新；手动安装可 `git pull` 后重启。升级前建议备份 `data/plugin_data/astrbot_plugin_emotionai_pro/`。
- **备份**：管理员可发送 `/备份数据`；数据同时保存在插件数据目录的 `backups/` 下。
- **卸载**：在插件市场卸载，或删除 `data/plugins/astrbot_plugin_emotionai_pro/`；插件数据默认保留，确认不再需要后再删除 `data/plugin_data/astrbot_plugin_emotionai_pro/`。

### 数据与隐私

插件数据默认位于：

```text
data/plugin_data/astrbot_plugin_emotionai_pro/emotionai_pro/
├── user_emotion_data.json   # 好感度、亲密度、阶段、描述
├── long_term_memory.json    # 长期记忆片段
├── global_mood.json         # 全局心情
└── backups/                 # 自动/手动备份
```

这些文件只保存在本地；插件不会额外上传到第三方服务。使用辅助 LLM 做情感分析时，对话片段会按 AstrBot 的模型配置发送给对应 provider，请按自己的隐私要求选择模型与网络环境。`global_privacy_level` 控制的是聊天中的展示程度，不改变本地存档内容。

## 更新日志

### v4.2.0（当前版本，2026-10-20：好感度驱动的记忆与态度 + 心情增强）

- 好感度现在真正决定“记住什么、想起什么、怎么说话”：高好感记更多、召回更多具体片段；低好感只记冲突与边界，态度更冷；
- 关系阶段每轮实时刷新，新增【关系基线】与心情倾向；心情只能修饰语气，不能把冷淡演成亲昵；
- 所有动态注入仍只追加在用户消息之后，且标记为不落盘——不碰历史前缀，也不污染会话记录；
- 修复注入随消息落盘、`[需要情感评估]` 残留、退出时覆盖记忆、阶段长期停在旧值等问题。

### v4.1.17（2026-10-19：情感分析专家链移除 Qwen3-VL 视觉模型）

- 将 `siliconflow/Qwen/Qwen3-VL-30B-A3B-Instruct` 移出情感分析专家链：它是视觉模型，作为纯文本情感分析的兜底既慢又不稳，失败时还会白占一次 15 秒时间片；
- 只从专家链排除，provider 本身仍保留在 AstrBot 配置里，`meme_manager` 的 `auto_collect` 等视觉功能按需仍可使用；
- 即使有人把辅助 LLM 显式配置成该模型，也不会进入专家链；专家链候选从 13 个降为 12 个；
- 新增 3 项回归测试，全量 690 项通过。

### v4.1.16（2026-10-19：公开仓库去个人化）

- 清理公开仓库里的个人配置痕迹：测试与注释中的 QQ、群号、bot 人设名、自定义阶段名改为通用占位，避免把某个人的使用配置带进通用版本；
- 情感分析提示词的描写角度改用配置里的 `bot_name`，不再硬编码某个人设名；对现有用户的行为等价；
- `.gitignore` 补充本地配置文件、运行数据、数据库、日志、密钥、部署临时文件与 `HANDOFF.md` 的忽略规则，降低以后误提交个人配置的风险；
- 全量测试 687 项通过。

### v4.1.15（2026-10-19：关系 / 态度描述不再千篇一律）

- 优化「/查看好感」「/好感度」里的关系与态度描述：提示词会带上上一版和最近用过的描述，每轮轮换一个具体描写角度，并明确区分「关系＝双方关系的具体样子」与「态度＝这一轮具体怎么回应」；
- 显式避开线上高频套话（傲娇、撒娇、俏皮、互怼、损友……）和空话（友好交流、正常关系、陌生人、中立）；
- 模型返回套话堆砌、近重复或空字段时，按关系远近分五档换成更具体的兜底文案；同一用户稳定挑选，不会每轮随机跳；
- 每条用户记录保留最近 5 条关系 / 态度描述，旧存档自动兼容；新增 58 项测试，全量 686 项通过。

## 核心亮点

| 特性类别 | 亮点说明 |
|----------|----------|
| **双重情感系统** | 保留 8 维情感 + 好感/亲密度双核，新增「复合评分」「动态权重」与「负好感专属权重」 |
| **真实心理模拟** | AI 自主生成态度/关系描述，新增「辅助 LLM 情感分析专家」与「好感度驱动的长期记忆」，避免数值跳变 |
| **好感驱动记忆** | 好感高记得更多细节、更愿意主动提起；好感低只记冲突/边界、态度更冷；每轮按相关性 + 时间 + 情绪价召回具体记忆片段 |
| **关系阶段系统** | 四阶段（初识→深化→承诺→共生）+ 负向三档（冷淡/反感/敌对），阶段名称可自定义；新增「滞后带过渡保护」「亲密度增益」与「阶段进度百分比」 |
| **智能更新机制** | 不再依赖尾部标记：①关键词情绪强度 ②时间阈值 ③强制计数器 ④主 LLM 标记 四维决策 |
| **高交互性** | 排行榜、阶段分析、情感档案、隐私控制，新增「缓存统计」「数据备份/修复」「调试事件/记忆」 |
| **隐私与性能** | TTL 缓存、异步自动保存、数据迁移、全局隐私级别，新增「负好感惩罚」「抵御操纵提示」 |

## 配置说明（`_conf_schema.json`）

| 配置键 | 说明 | 默认值 |
|--------|------|--------|
| `enable_attitude_system` | 启用 FavourPro 态度关系系统 | `true` |
| `enable_ai_text_generation` | AI 自主生成态度/关系描述 | `true` |
| `enable_secondary_llm` | 启用辅助 LLM 做情感分析 | `true` |
| `enable_smart_update` | 四维智能更新（关键词+时间+计数+标记） | `true` |
| `force_update_interval` | 强制更新间隔（对话次数） | `5` |
| `emotional_significance_threshold` | 长期记忆基础阈值；好感度会在此基础上动态加减 | `5` |
| `enable_memory_recall` | 是否注入具体记忆片段（关闭后只注入统计） | `true` |
| `memory_recall_max_items` | 单轮最多召回几条具体记忆 | `6` |
| `mood_memory_bias` | 心情一致记忆召回（开心想好事、低落想冲突） | `true` |
| `mood_influence_strength` | 心情对语气的影响强度（0~1） | `0.7` |
| `global_privacy_level` | 全局隐私级别（0~2） | `1` |
| `session_based` | 是否按会话隔离情感 | `false` |

### 动态权重与过渡保护

| 阶段 | 好感权重 | 亲密权重 | composite 阈值 | 过渡缓冲 | 亲密度增益 |
|------|----------|----------|-----------------|----------|------------|
| 初识期 | 70 % | 30 % | 25 | 3 分 | ×4.0 |
| 深化期 | 50 % | 50 % | 55 | 5 分 | ×3.6 |
| 承诺期 | 30 % | 70 % | 80 | 7 分 | ×3.0 |
| 共生期 | 50 % | 50 % | 95 | 10 分 | ×1.0 |

- **滞后带**：上升阈值 > 下降阈值，防止阶段抖动
- **保护分**：过渡期间复合评分不会低于前一段最高值
- **增益**：过渡期亲密度成长倍率提升，助力平滑进阶

## 设计理念

> 不是简单“好感度加减”，而是「**真实·渐进·可养成·可运维**」的 AI 内心世界。

### 保留

- 8 维情感模型与异步高性能架构
- AI 自主文本评估与真实心理模拟
- 完备管理工具与排行榜体系

### 新增

1. **智能更新**：四维判断（关键词/时间/计数/LLM 标记），无需等待尾部标记
2. **辅助 LLM**：独立情感分析专家，结合当前关系/情感状态与最近描述，第一人称口语生成态度/关系描述
3. **长期记忆**：短期 TTL + 长期落盘 + 重要事件队列；好感度决定写入门槛、保留条数与召回数量，跨重启保留关系轨迹与具体经历
4. **负好感支持**：负好感阶段专属权重（好感 100 %）与描述策略，支持“冷淡/反感/敌对”三档
5. **过渡保护**：滞后带 + 保护分 + 亲密度增益，阶段跃迁平滑不掉级
6. **缓存与备份**：TTL 命中率统计、自动保存、数据备份与迁移、互动统计修复
7. **隐私与运维**：全局隐私级别、抵御操纵提示、调试事件/记忆指令、异步锁粒度优化
